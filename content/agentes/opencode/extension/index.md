title: Extender OpenCode
---

Mecanismos para ampliar lo que OpenCode sabe y puede hacer: agentes, skills, comandos, plugins, MCP y políticas de permisos.

- [[agentes/opencode/extension/agentes|Agentes y subagentes]] — perfiles con prompt, modelo y permisos propios.
- [[agentes/opencode/extension/skills|Skills]] — instrucciones reutilizables con `SKILL.md` y archivos de apoyo.
- [[agentes/opencode/extension/comandos|Comandos personalizados]] — plantillas de prompt con argumentos y shell.
- [[agentes/opencode/extension/plugins|Plugins]] — servidor, TUI, escritorio, hooks y herramientas.
- [[agentes/opencode/extension/mcp|MCP]] — servidores locales y remotos, OAuth y Code Mode.
- [[agentes/opencode/extension/permisos-politicas|Permisos y políticas]] — reglas `allow`/`ask`/`deny` y bloqueos duros.
