title: Extender Claude Code
---

Mecanismos para ampliar lo que Claude Code sabe y puede hacer: skills, subagentes, hooks y MCP.

- [[agentes/claude/extension/skills|Skills de Claude]] — módulos de capacidad instalables con activación automática.
- [[agentes/claude/extension/subagentes|Subagentes de Claude Code]] — sesiones aisladas para delegar tareas con su propio contexto.
- [[agentes/claude/extension/hooks|Hooks de Claude Code]] — automatizaciones deterministas en el ciclo de vida del agente.
- [[agentes/claude/extension/mcp|MCP (Model Context Protocol)]] — conector universal con herramientas externas y APIs.
